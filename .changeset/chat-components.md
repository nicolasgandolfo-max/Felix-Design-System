Add the chat component family from Figma (Félix DS 2026 → "New components chat"):

- `Marker` (atom) — thread annotation with `default`, `separator` and `border` variants.
- `Bubble` (atom) — message body with `default`, `secondary`, `muted`, `tinted`, `outline`, `ghost` and `destructive` variants.
- `Message` (molecule) — compound `Message` / `MessageAvatar` / `MessageContent` / `MessageHeader` / `MessageFooter`, aligned `start` or `end`.
- `Attachment` (molecule) — file/image chip in `sm` / `md` / `lg` sizes and `default` / `error` / `loading` states.
- `MessageScroller` (organism) — compound `MessageScroller` / `MessageScrollerHeader` / `MessageScrollerEmpty` / `MessageScrollerMessages` / `MessageScrollerInput`.
